# 최종 합의 방향 (이전 RL 전면 적용 설계를 대체)

## 핵심 아이디어
전체를 RL로 풀지 않는다. 해석적/규칙 기반으로 충분히 되는 부분(실패 유형 분류: 트레이 점유+그리퍼 폭, 행동 선택 로직)은 그대로 두고, **유일하게 규칙이 구조적으로 약한 지점 — 후보 다음-시점(next-view)의 정보량 스코어링 — 에만 가벼운 지도학습 모델을 넣는다.** RL도 아니고 Isaac Lab 병렬 학습도 필요 없음 — Isaac Sim은 라벨 생성용으로만 가볍게 사용.

## Phase 1 (4~6주): 규칙 기반 시스템 + 경량 학습 next-view 스코어러
1. eye-in-hand hand-eye 캘리브레이션 전환, 저차원 state 추출기(가림도, 포즈 신뢰도) 실물 구현
2. 성공/실패/판정불확실 3단 분류기(트레이 점유+그리퍼 정보) 구현·검증
3. 베이스라인 B0(열린루프)/B1(고정 재관측)/B2(기하학적 휴리스틱 NBV) 실물 구현
4. Isaac Sim에서 (장면 상태, 후보 시점) → 실제 정보량 개선 여부를 ground truth로 라벨링해 다수 생성
5. 경량 회귀/분류 모델(소형 MLP 등) 지도학습 → next-view 스코어러로 교체한 조건 C 구성
6. 비교: B0/B1/B2 vs C(학습 스코어러) vs (참고용) VLM 기반 스코어링 — 성공률·재시도횟수·소요시간
7. 이 전체가 Phase 1 산출물 = 실물에서 자동으로 쌓인 (관측, 행동, 결과) 로그 데이터셋

## Phase 2 (추후, 사람 시연 없이 시작 가능): VLA/디퓨전 정책 파인튜닝
- Phase 1에서 쌓인 자동 라벨 로그를 시연 데이터로 재활용(사람 teleoperation 불필요가 핵심 이점)
- SmolVLA 등 경량 VLA 후보로 파인튜닝, Phase 1의 검증된 규칙기반 시스템을 베이스라인/안전 폴백으로 비교
- 이 시점에 가서 GPU/데이터 상황 보고 scope 재조정
